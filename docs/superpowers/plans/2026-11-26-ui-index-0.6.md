# Unity 2022.3 UI 索引与快速复测（0.6.x）

状态：设计与任务门禁；实现和加速数据尚未验收。开发分支：`codex/ui-index-0.6`，基线 `38e8a9c`。Unity 验收仅用 2022.3.62f2；不改、提交或推送生产测试工程，不启用额外模型，不发版。CLI、UPM、Bridge 与 lock 在功能分支同步到 0.6.0，0.5.0 改动保留各自变更日志。

## 1. 实证：到底慢在哪

- 前次真实 Launcher 测试的本地 Watch 事件流：首尾 **396.466 s**，11 条已记录命令各自的开始/结束时间相减、相加为 **37.375 s**。其中 Play Mode 入口 23.799 s，5 次截图约 11.391 s，2 次 hit-test 各 25 ms、2 次点击 29/25 ms，退出 2.082 s。约 359 s 落在命令之外，包含 Agent 看图、分析、交互调度和流程间隔，现有事件无法再细分。该记录是单次真实试点，不是可复现性能基准，不用总时间推算提速倍数。
- 只读 Git 清单：该试点工程跟踪了 12,225 个 `.prefab` 和 256 个 `.unity`。这证明全量工作集值得单独控制，不代表 12,225 个都是 UI，也不是 AssetDatabase 枚举的实测速度。
- 现有 [HierarchyController](../../../packages/com.mk.unity-agent-bridge/Editor/Features/Hierarchy/HierarchyController.cs) 的 `find` 支持分页和扫描预算；[InteractionController](../../../packages/com.mk.unity-agent-bridge/Editor/Features/Interaction/InteractionController.cs) 已可按运行态路径点击；[UGUI 后端](../../../packages/com.mk.unity-agent-bridge/Editor/Adapters/UGUI/UguiInteractionBackend.cs) 逐次算当前屏幕坐标、检查顶层命中与可交互性。没有理由把这套守卫换成离线坐标、强制点击或直接调用 onClick。
- [Unity 2022.3：FindAssets](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AssetDatabase.FindAssets.html) 支持限定目录和资产类型；[LoadAssetAtPath](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AssetDatabase.LoadAssetAtPath.html) 读取导入对象；[GetAssetDependencyHash](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AssetDatabase.GetAssetDependencyHash.html) 用于判断导入依赖变化，不能用单个文件 mtime 代替。是否可靠覆盖变体、嵌套和删除由真实测试核对，而非由 API 名称推断。
- [Unity 2022.3：GUID + Local File ID](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AssetDatabase.TryGetGUIDAndLocalFileIdentifier.html) 标识序列化来源；[GlobalObjectId](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/GlobalObjectId.html) 的场景解析受场景加载/保存限制；[Prefab 来源映射](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/PrefabUtility.GetCorrespondingObjectFromSource.html) 对嵌套实例有层级语义，可能返回空。结论是**资产身份和运行态实例身份必须分开**，不把 GUID 当点击句柄。
- [UnityEvent 持久方法名](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Events.UnityEventBase.GetPersistentMethodName.html) 只提供序列化监听器线索；[AddListener](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Events.UnityEvent.AddListener.html) 添加非持久监听。上次真实 Launcher 上有运行时 Lua 注册的 Button，静态资产不能保证推断实际效果。同样， [Poco UGUI 运行态节点实现](https://github.com/AirtestProject/Poco-SDK/blob/master/Unity3D/ugui/UnityNode.cs) 和 [AltTester SDK 架构](https://github.com/alttester/AltTester-Unity-SDK/blob/development/Docs/source/pages/overview.md) 都支持运行态结构查询；这证明方案有先例，不提供本项目的速度证据。

## 2. 对比与选型

| 方案 | 优点 | 缺点 | 可核验的选择结论 |
|---|---|---|---|
| A：仅运行态树、短生命周期索引或结构化查找 | 反映动态 UI、Canvas 和实例；老 Bridge 可由现有 hierarchy/click 做路径级复测；冷启动改动小 | 看不见未加载面板；大树和列表频繁变动，快照缓存容易过期；无法回答「工程里有没有这个界面」 | 用作当前状态的权威及跑基线。不单独作为方案，无法支撑项目同步 |
| B：仅静态离线解析 Prefab YAML/.meta，缓存控件名和方法 | 不用启动 Editor；方便做增量文件读取；纯本机可重建 | 序列化模式、嵌套和 Override/Variant 解释成本高；不了解运行时实例、监听器和遮挡；不能安全直接派发 | 只读研究或索引排序线索有价值，不作为默认解析器或点击依据 |
| C：AssetDatabase 静态增量目录 + 运行态校验 + 独立人工/Agent 语义 | 同时发现未加载目标与复用已知路线；Unity 自身解释导入资产；分开管理机器事实与玩法语义；可避开大多数已知目标的看图轮次 | 0.6 Bridge 要新增扫描与校验能力；冷同步有成本；动态控件不能靠 Prefab 证明；需要真实正反例 | **首选**。只有运行态通过约束才允许点击；找不到就降级到只读发现，不自动换点 |
| D：图像模板或多模态/Agent 看图缓存 | IMGUI、UI Toolkit、自绘界面也可以发现；适合视觉验收 | 分辨率、画布状态和本地化改变后不稳定；有模型/截图成本；既有坐标不能作为稳定定位符 | 作为探索和画面断言的兜底，不用于烘焙绝对坐标 |

综合排序按运行正确性（硬门槛）、动态覆盖、重复测试往返、增量可维护性、投入风险依次权衡。静态索引提供候选，不给候选点击授权；不用单次耗时虚构权重评分。

## 3. 拟交付合同

1. `unityctl ui-index sync [--root Assets/…] [--full]`：通过本机 Bridge 在 Edit Mode 获取导入的 UGUI Prefab；默认扫描 Assets 的合法 Prefab 类型，可按目录缩小；报告扫描、命中、跳过、更新、删除、未识别、耗时。先枚举 GUID 与依赖指纹，仅抽取变化资产；重命名保留来源身份，删除清理，其他 scope 不被误删。完整失败不覆盖上一份完整缓存；慢任务用既有 job 机制并分批让出 Editor update。先验证直接读取持久 Prefab 的方案；若嵌套实测不足，受限使用隔离 Prefab 内容加载并保证卸载，绝不自动保存/导入/启动。
2. 缓存与人写知识分离：只存工程本地可重建的有限元数据。首选 stdlib SQLite（事务、一致更新、唯一索引、便于按 scope 查询），缓存存工程 `Library/UnityRunBridge/`，不跟随 Git 或分发。存项目/缓存 schema、导入指纹、资产路径、GUID、local fileID（字符串保存，不丢精度）和无歧义的根内路径；同名、嵌套和无身份都不静默合并。捕获有限的持久回调类型/方法名，不存参数、任意字段内容、截图或账号；资产名不能自动定义业务作用。
3. `ui-index find` 本地离线按名称、路径、类型或显式别名查找，展示范围、来源、同步状态和歧义；不把离线结果声称为已验证在线。不使用额外模型；Agent 可依据源码或运行记录补作用与范围，需显式写入现有工程知识目录/独立注释层，不写回可重建缓存。注释区分源码推断、人工说明、实机验证；不自动选择多个候选中的第一项。
4. `ui-index resolve` / `ui-index click`：运行态场景+已验证 UI 根+根内控件身份；按给定 scope 唯一解析，在同一个主线程请求内验证预期目标，再使用既有非 force 派发。连续校验包括资源来源可证明时的同源检查、当前节点存活/可交互、最上层射线命中、当前分辨率；不能证明 Prefab 映射的动态实例只能用经过显式验证的运行路径作为另一类型绑定，不能猜测来源。不可用、陈旧、范围不匹配、歧义和遮挡均返回清晰失败码，无点击、记一次审计。保持旧版命令行为；用 doctor 检查新增能力，旧 Bridge 不回退到未核验的坐标点击。
5. 若 Prefab 暂未实例化或界面纯动态，从已受限的 hierarchy 或截图获取线索；保留这些通用工具和既有玩法知识，不引入游戏业务路由或固定场景。只把已经有同等断言的已知步骤从视觉工具替换成结构化点击，文字截断等仍要视觉验收。

## 5. 性能验收口径

- 先用隔离的 Unity 2022.3 工程：至少两种布局、预制/动态目标、改变覆盖层和活跃面板。先热身，再交错跑对照线路，同一可观察结果。每条可比较路径至少 20 个有效样本，记录每次操作、失败率、p50/p95、调用数和传输字节。按实际样本汇报，不能拿初次打开 Editor 或 Agent 停顿计入点击提速。
- 分列首次构建、无变化同步、单个 Prefab 改动、依赖波及、离线查询、运行态 resolve/click。隔离工程测 10/100/1,000 个 Prefab 的成本曲线（样本规模取实际部署可跑结果），试点工程只有经允许的只读规模证据或隔离副本，禁止更改原工程以装候选包。
- 安全验收是硬门槛：明确的危险反例必须 **0 次非预期回调**；已知目标路径必须通过同样的断言。性能验收的预设目标：已知定位的热路径比「截图 → 探测 → 点击」减少至少两次用户层 CLI 调用；报告是否快于已有 hierarchy+路径，不预设百分比或把新增同步视为零成本。冷同步不能退化成每测试步骤重扫；未达到的指标照实指出。
- T5 报告给出可复跑命令和本地脱敏证据；区分真实 Unity、模拟和未验证。暂不把整机或玩法测试速度的提升归因于本功能。

  --unity "/Applications/Unity/Hub/Editor/2022.3.62f2/Unity.app" --output "$PWD/.tmp/ui-index-baseline"

用临时生成的 UGUI 弹窗工程，以独立回环端口启动。每个布局先热身三条路径，再轮换顺序执行，目标是每条路径有至少 20 个成功样本；被拒绝的尝试单独记录并确认未打开弹窗。每次成功均验证弹窗打开，再调用夹具专用复位探针并核对初始状态，复位不计入候选点击用时。脚本记录 CLI 子进程总耗时（包含启动和连接）、JSON 字节、PNG 文件体积及独立的 Play/Stop 和复位耗时。图像组用夹具已知目标中心代替 Agent 看图，测量的是工具调用开销下限，不包括图片推理耗时。已有精确路径单独列为对照，不能将它已有的加速算作新索引的收益。

### 扫描接口（T2）

`POST ui-index/scan` 仅在安装 UGUI Adapter 时注册，且只允许在空闲 Edit Mode 调用。请求为 `{"root":"Assets","known":{"<asset-guid>":"<dependency-hash>"}}`；`known` 可省略（全量）。客户端必须按同一目录、schema 和项目来源送旧指纹；跨目录数据不能混用。返回 Job ID，通过既有 jobs 接口等终态。成功结果包含 schema、实际目录、计数、耗时和本机 `Library/UnityRunBridge/ui-index-results/<job-id>.jsonl` 文件。每行包含当前 Prefab 的 GUID、实际路径、依赖指纹与 changed；只有变化项带 controls。不存在于当前完整结果的旧 GUID 由调用端按 scope 清理。没有写入持久 SQLite，接入及消费后清理属于 T3。

导入后持久 Prefab 直接读取，不打开编辑器场景、不实例化对象，也不执行回调。双同名控件由根内路径段的 siblingIndex 区分；序列化 fileID 用字符串；未知身份保留为未知。只采集候选组件与持久 Button 回调名/目标类型，不读取任何参数或正文。NOUGUI 不注册该能力。资产版本在跨帧扫描期间改变、Editor 退出空闲态、单 Prefab 超 4096 控件、scope 超 10 万 Prefab 或文件过 256 MiB，均失败且不发布半成品。分帧为最多 32 资产/约 6 ms 的软预算，首次 AssetDatabase 枚举、单个大资产加载不能抢占。暂无真实项目容量结论；T5 专测规模曲线。

Unity 2022.3.62f2 实测：UGUI/Legacy 366 通过、0 失败、4 跳过；NoUGUI/Legacy 305 通过、0 失败、6 跳过。新增用例验证真正导入的同名嵌套节点、Variant 禁用覆盖、持久回调和非持久监听区别、基础 Prefab 改动引发三项重扫、无变化零重扫、重命名保留 GUID、删除和非法 scope/指纹拒绝。扫描前后夹具中的 Prefab、meta、manifest、ProjectVersion 文件字节一致。

### 安全运行时执行（T4）

首轮真实夹具显示：Unity 2022.3.62f2 的已保存场景实例在 Edit Mode 有 Prefab 来源，进入 Play Mode 后两个 Prefab 来源 API 均返回空；只靠名称会产生危险的假命中。当前方案加入只读 `ui-index bind`：用 Unity Editor 的来源 API 在已保存且未修改的场景中核验资产与组件，只在当前 Editor SessionState 保留绑定。运行态同时复核场景与 Prefab 指纹、根与组件的场景对象身份、实际子槽位。在 2022.3.62f2 夹具观测到 Edit/Play 的归一化 ID 对应，此行为不是 Unity 跨版本 API 保证；不匹配即失败，绝不按名称降级。动态路径使用当前 Hierarchy 观测的 instanceId + 路径，签发短期一次性凭证。

实机正反例：15 次 Bridge 点击请求各有一条审计，静态与动态各触发一个预期回调，13 次拒绝未触发非预期回调。覆盖重复实例根、运行时同名替身、无来源克隆、改名、同名兄弟换序、遮挡、禁用、不激活、指纹变更、未加载和实际切换场景、凭证改名失效及重放。公开 0.4.1 本地 UPM 在真实 Unity 中拒绝两个新命令、无旧接口回退；UGUI 与 NoUGUI EditMode 分别 366/305 通过、均 0 失败（跳过 4/6）。Python 497 项通过。新命令的延迟分布、完整九配置和最终打包验收仍属于 T5。

复跑：`scripts/run-unity-smoke.py indexed-click --unity <2022.3.62f2 Unity>`；旧版使用 `indexed-legacy --upm <0.4.1 tgz>`。两者均使用隔离工程。
